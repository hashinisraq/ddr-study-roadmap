Burst Length 16 (BL16)

The natural partner of the 32-bit sub-channel: double the burst so one access still moves a full cache line.

The arithmetic

Channel widthBurstPer access
DDR464-bitBL88 × 64 b = 64 bytes
DDR532-bit sub-channelBL1616 × 32 b = 64 bytes
Why keep it at 64 bytes A CPU cache line is 64 bytes, so memory accesses are naturally cache-line sized. DDR5 had to preserve that granularity while narrowing the channel - BL16 is how. Same useful chunk, now delivered over two independent sub-channels.
