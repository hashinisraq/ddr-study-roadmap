DDR5 Modules & the Registering Clock Driver

How the DDR5 module is built - PMIC, SPD hub, temperature sensors, and the RCD that buffers each sub-channel.

The RCD (Registering Clock Driver)

DDR5 RDIMMs use an RCD - the evolution of DDR4's register (Phase 1, Lesson 12). It buffers the command/address and clock for the chips, reducing the load the controller must drive. Because DDR5 has two sub-channels, the RCD buffers them accordingly.

The DDR5 module, assembled

ComponentRoleIntroduced / changed
RCDBuffers CA + clock (per sub-channel) on registered modulesEvolves DDR4's register
PMICOn-module voltage regulation (Lesson 9)New in DDR5
SPD hubHolds module identity/timing configUpdated for DDR5
Temp sensorsReport module temperatureOn-module in DDR5
Spec note These module-level parts (RCD, PMIC, SPD hub) are defined in the JEDEC module standards, not the DDR5 device spec. When you reach Phase 3, look to the module specs (UDIMM/RDIMM/LRDIMM) for these - the device spec covers the chip itself.
