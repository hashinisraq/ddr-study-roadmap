Phase 2 · Lesson 5

Link / System ECC & CRC Changes

Beyond on-die ECC, DDR5 adds and refines error protection on the bus and at the system level - layers that each catch a different class of error.

Layers of protection

Think of DDR5 error handling as nested layers, from inside the cell array outward:

LayerWhereCatches
On-die ECC (Lesson 4)Inside each chipSingle-bit errors in stored cells
CRC on the linkOn the data bus (DQ)Corruption while data crosses the wires
System / link ECCController + moduleErrors across the whole transfer, often correctable

What changed vs DDR4

DDR4 had write-data CRC and (on ECC modules) system ECC. DDR5 refines the CRC scheme on the link and strengthens system-level ECC, so more error classes are detected and corrected end to end. The net effect: data is checked inside the array, again as it crosses the bus, and again at the system level.

Why so many layers Higher speeds and denser cells mean more chances for a bit to go wrong - in storage and in transit. Each layer targets a different failure point, so together they keep the overall error rate acceptable despite DDR5's aggressive speed and density.
