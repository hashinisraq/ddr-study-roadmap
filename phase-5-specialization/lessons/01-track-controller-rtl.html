Phase 5 · Track 1

Track: Memory Controller / RTL Design

Design the digital logic that drives the DRAM - command scheduling, address mapping, refresh management, timing enforcement.

What you actually do

You build the hardware that decides, every cycle, which command to issue to which bank while honoring every timing. The core skill is scheduling: choosing the next request to maximize row hits and bank parallelism (a classic policy is FR-FCFS - first-ready, first-come-first-served, which prefers a ready row-hit). You also choose open-page vs closed-page policy and the address-mapping that spreads accesses across bank groups.

What to learn

  • Verilog / SystemVerilog and digital design practice.
  • Queueing and arbitration; request scheduling algorithms.
  • Controller/PHY IP documentation (Synopsys, Cadence).
  • Deepen Phase 1 timings and Phase 4 scheduling ideas - now realized in hardware.
Build to learn A concrete project: implement a simple scheduler that prefers row hits, and measure its bandwidth against a naive in-order one in a simulator (Phase 4). The gap is the value of good scheduling.
