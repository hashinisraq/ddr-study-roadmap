Phase 5 · Track 5

Track: System Architecture / Performance

Decide how memory fits into a whole system and how to extract the most from it - and explore where DRAM is heading next.

What you actually do

You reason about bandwidth, latency, and access patterns at system scale, and evaluate new ideas: processing-in-memory (PIM), smarter refresh, and reliability/security like RowHammer defense. You model systems and read the research frontier.

What to learn

  • System-level simulation (gem5) and workload analysis.
  • Memory Systems (Jacob, Ng & Wang) in depth.
  • The SAFARI group (Onur Mutlu, ETH) publications - RowHammer, refresh optimization, PIM - the frontier of DRAM research.
  • Conference papers: ISCA, MICRO, HPCA, DATE memory sessions.
Build to learn A concrete project: take a real workload, run it in gem5 with two memory configurations, and explain the performance difference in terms of row locality and bank parallelism - then read one SAFARI paper that proposes improving exactly that.
Phase 5 milestone Pick one track (this or another). Write a half-page plan: the sub-skills it needs, the spec sections to master, and one concrete project you'll build to prove you can do the work. Then start it - that project is where "hero" actually happens.
