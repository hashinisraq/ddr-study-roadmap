Phase 5 · Track 4

Track: Firmware / Training

Write the code that brings the memory link up at boot and tunes it - the world of Phase 1 §7 and Phase 2 §11, taken professional.

What you actually do

You implement the training algorithms that center every sampling point in its eye: write leveling, read/DQS gate training, Vref training, CA/CS training, and duty-cycle adjust (DDR5). This is the memory reference code (MRC) that BIOS/UEFI runs before the system can use RAM.

What to learn

  • The init/training sections of the spec (Phase 3), in depth.
  • Embedded C and low-level register programming (the mode-register maps).
  • BIOS/UEFI MRC concepts and platform bring-up flow.
Build to learn A concrete project: write pseudocode for a full training sequence - power-up → ZQ → write leveling → read training → Vref - with the pass/fail criteria at each step. DDR5 adds more steps and per-sub-channel tuning, but the goal never changes: center the eye.
