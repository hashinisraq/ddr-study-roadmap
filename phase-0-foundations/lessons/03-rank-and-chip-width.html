How Chips Team Up: Rank and Chip Width

Why a stick has several chips instead of one, and what "rank" means - explained without any electronics.

The CPU wants a lot of bits at once

Computers move data in chunks of bits (a bit is a single 0 or 1). When the CPU asks memory for data, it wants 64 bits at a time on one connection (called a channel). One memory chip can't comfortably hand over 64 bits by itself - so several chips work together, each contributing a share.

Chip "width": how many bits each chip gives

Each chip delivers a small number of bits at once - its width:

  • A "x8" chip gives 8 bits at a time (the most common).
  • A "x4" chip gives 4 bits (used on big server sticks).
  • A "x16" chip gives 16 bits (common in laptops).

To reach 64 bits with x8 chips, you need eight of them side by side (8 chips x 8 bits = 64 bits). That is why a typical stick has eight chips.

That team of chips is a "rank"

A set of chips that work together to deliver the full 64 bits is called a rank. Think of a rank as one complete team. A stick can hold:

  • One rank (single-rank) - one team of chips, or
  • Two ranks (dual-rank) - two teams on the same stick, taking turns.
Why remember "rank" "Rank" is a word you'll see constantly in DDR. All it means is: a group of chips that together make up one full-width (64-bit) unit the memory controller talks to. Nothing more mysterious than that.
Analogy Eight people each carrying one box = a rank delivering a full load. A dual-rank stick is like having two such teams that take turns at the loading dock.
