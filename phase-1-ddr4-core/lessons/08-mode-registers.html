Mode Registers (MR0-MR7)

The chip's settings panel. You configure latencies and features by writing mode registers with the MRS command.

What lives where

RegisterConfigures (roughly)
MR0CAS latency (CL), burst length, read burst type.
MR1DLL enable, output drive strength, ODT values, write-leveling enable.
MR2CAS write latency (CWL), dynamic ODT, temperature-controlled refresh.
MR3MPR (multi-purpose register) mode, fine-granularity refresh.
MR4CAL, gear-down mode, read/write preamble, various controls.
MR5CA parity, data-bus inversion (DBI), ODT input buffer.
MR6tCCD_L setting, DQ Vref training controls.

How to think about it

You do not memorize the bit layouts. You learn two things: (1) that configuration lives in mode registers, and (2) how to look up a given setting's register and bits in the datasheet when you need it. The exact fields are reference material - the structure is what you keep in your head.

Where you'll use this During initialization (Lesson 7), the controller writes these registers to pick CL, CWL, burst length, ODT, DBI, and which features are on - matching the chip to the board and the target speed. DDR5 keeps the idea but explodes the number of registers (Phase 2).
