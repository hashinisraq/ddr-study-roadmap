Phase 1 · Lesson 5

Burst Length, Prefetch & Auto-precharge

How one READ moves a whole cache line, how a slow array feeds a fast bus, and how to close a row automatically.

Burst length 8 (BL8) = one cache line

DDR4 transfers data in a fixed burst of 8 beats per DQ pin. Across a 64-bit rank that is 8 × 64 bits = 64 bytes - exactly one CPU cache line. DRAM bursts are deliberately sized to cache lines.

The 8n prefetch: slow array, fast pins

The internal array is wide but slow; the external bus is narrow but very fast (double data rate). On a read the chip grabs 8 columns at once internally (the "8n prefetch"), then shifts them out fast on the pins.

Auto-precharge: close the row automatically

If you know you won't reuse the open row, issue RDA / WRA (read/write with auto-precharge, flagged by address bit A10). The bank closes itself right after the burst - no separate PRE needed.

  • Use it for random access (each row touched once).
  • Skip it when you will read more columns from the same open row (row hits are cheap - keep the page open).
Open-page vs closed-page Whether to leave rows open (bet on reuse) or auto-precharge (bet on randomness) is exactly the controller "page policy" you will tune in Phase 4. Access pattern decides which wins.
