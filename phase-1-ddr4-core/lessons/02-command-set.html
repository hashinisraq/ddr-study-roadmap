The Command Set (the verbs)

Everything the DRAM ever does is a sequence of a handful of commands on the command/address bus. Learn the verbs and when each one is legal.

The commands

CommandWhat it doesCarries
ACTIVATE (ACT)Open a row in a bank into its row buffer.Bank + row address
READ (RD)Read a burst of columns from the open row.Bank + column address
WRITE (WR)Write a burst of columns into the open row.Bank + column address
PRECHARGE (PRE)Close the open row; reset the bit lines.Bank (or all banks)
REFRESH (REF)Top up leaking cells (Phase 0).-
MODE REG SET (MRS)Configure chip settings (latencies, features).Register + value
NOP / DESDo nothing / deselect this cycle.-

Row address with ACT, column address with RD/WR

Notice the split: the row address rides with ACTIVATE (you open a whole row), and the column address rides with READ/WRITE (you pick columns out of the already-open row). This two-step addressing is a direct consequence of the row-buffer model from Phase 0.

The canonical sequence A read of a fresh location is always ACT → RD → PRE: open the page, read from it, close it. A write is ACT → WR → PRE. Refresh (REF) and configure (MRS) are housekeeping around that core loop. If you can narrate ACT→RD→PRE, you understand how DRAM is driven.
Analogy ACT = open the filing cabinet drawer (the row). RD/WR = take out or put in specific folders (columns). PRE = close the drawer so you can open a different one. REF = the clerk walking the aisles rewriting fading labels.
Check yourself
  1. Which command carries the row address, and which carries the column address?
  2. Write the command sequence to read one fresh location and leave the bank closed.
  3. What is the difference between NOP/DES and a real command?
