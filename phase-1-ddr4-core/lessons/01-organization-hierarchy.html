The Organization Hierarchy

From the stick you plug in down to a single cell - the nested containers every DDR command targets.

The chain, outside in

LevelWhat it is
ChannelOne 64-bit data path from the memory controller.
DIMMThe physical module you plug in; a channel holds one or more.
RankA group of chips selected together by one chip-select (CS), forming the full 64 bits (72 with ECC).
Chip (device)One DRAM package. e.g. eight ×8 chips = a 64-bit rank.
Bank group → BankIndependent sub-arrays inside a chip, each with its own row buffer.
Row / ColumnThe grid inside a bank (Phase 0): a word line selects a row; bit lines are columns.
CellOne 1T1C bit.
Chip width (×4 / ×8 / ×16) A "×8" chip outputs 8 data bits, so eight of them make a 64-bit rank; "×4" (4 bits, big server DIMMs) and "×16" (16 bits, laptops) are the same spec at different widths. Narrower chips → more chips per rank → more banks available in parallel.
