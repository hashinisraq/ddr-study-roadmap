Phase 4 · Lesson 2 · Exercise

Redraw the Bank State Machine from Memory

A short but revealing exercise: if you can draw it unaided and justify every arrow's timing, your Phase 1 foundation is solid.

The exercise

  1. On a blank page, draw the states: IDLE → ACTIVE → (RD/WR) → PRECHARGE → IDLE.
  2. Label each transition with its command (ACT, RD/WR, PRE) and the minimum timing that gates the next move (tRCD after ACT, tRAS before PRE, tRP after PRE).
  3. Write one sentence per arrow explaining the physical reason for its timing (tie back to Phase 0: sensing, restore, bitline reset).
  4. Now check it against the simplified state diagram in the JEDEC spec (Phase 3). Any mismatch is a gap - close it.
Why from memory Recognizing a diagram is easy; reproducing it is the real test. If you can regenerate the state machine and its timings unaided, you own the model instead of merely having seen it.
Self-grade
  1. Did you place all four states and three transitions correctly?
  2. Did you attach the right timing to each arrow?
  3. Could you justify each timing physically, without notes?
